# Phase 1: Systems, Files & CLI Tooling

This module covers building Python tools that interface directly with the Linux operating system, process logs, and execute system commands.

## Module Objectives
- [ ] **Drill 01:** Object-oriented file system manipulation (`pathlib`)
- [ ] **Drill 02:** System process execution & output capture (`subprocess`)
- [ ] **Drill 03** Hardware log parsing & pattern matching (`re` / regex)
- [ ] **Drill 04:** Command-line argument parsing (`argparse`)
- [ ] **Mini-Project:** Automated Linux System & Log Health CLI Utility

## Key Libraries
- `pathlib` - Modern, cross-platform path handling
- `subprocess` - Executing system comands and capturing stdout/stderr
- `re` - Regular expressions for log analysis
- `argparse` - Building production CLI interfaces
